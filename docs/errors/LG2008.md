# LG2008: Destructure

A destructuring pattern is invalid

## Common causes

A binding pattern lg cannot destructure: unsupported key forms in map destructuring, non-sequential patterns on non-sequential values, or malformed `:as`/`:or` clauses.

## What to do

Simplify the pattern. Map destructuring supports `keys`, `syms`, `strs`, `:or`, and `:as`.
