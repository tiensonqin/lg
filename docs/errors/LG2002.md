# LG2002: Type mismatch

A value's type does not match what the context requires

## Common causes

Passing a value of the wrong type to a function, collection, or annotation; an adaptation between incompatible types (e.g. `int` to `keyword`); or a return type that does not match the declared signature.

## What to do

Convert the value explicitly or adjust the annotation. When the mismatch involves an interop boundary, check that the host signature matches the declared types.
