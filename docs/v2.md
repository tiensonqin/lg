# lg v2 — design and work plan

Status: proposal. Builds on v1 (see design.md §9 for the standing
decisions: no `defprotocol`/`defmulti`, `dyn` stays confined, implicits
are a compiler feature not an OCaml dependency).

Ordered by priority; each item lists surface syntax, semantics, the
implementation path, and how we verify it.

## 1. Implicit parameters (dictionary-passing elaboration)

The flagship v2 feature — static, typeclass-style polymorphism without
protocols or multimethods.

**Surface.**

```clojure
;; an implicit parameter is declared with ^:implicit on a binding
(defn show [^any x ^{implicit showable} s] (s x))

;; call sites do NOT pass it — the inferencer resolves it
(show 42)          ;; resolves `showable` from the lexical env by type
```

An implicit value is an ordinary value whose type is a *dictionary type*
(record-of-functions, e.g. `^{:show (fn [a] string)}`). Resolution rules:

- At each call site, unify the implicit parameter's type and look the
  resolved type up in the *implicit table* — a per-module registry of
  `(type key -> value)` entries.
- Entries come from `^{:implicit …}` let/defn bindings in scope,
  innermost wins. Importing a module re-exports its implicit entries
  only if the caller's `(ns (:require …))` says `:implicits true`.
- No match → compile error listing the required dictionary type.

**Implementation.** Elaboration pass in `infer.ml`: implicit params
desugar to an extra trailing parameter; calls insert the resolved
dictionary argument. Emitted OCaml is an ordinary function taking a
record — zero runtime cost, fully checked.

**Verify.** `test/implicits.lg`: two dictionary instances for the same
key in nested scopes resolve innermost; cross-module resolution gated by
`:implicits`.

## 2. Cross-file mode signatures (`.lgi`)

Today every external binding conservatively escapes to `Shared`; `.lgi`
makes mode inference compose across modules.

- `lg modes` emits `<file>.lgi` next to each `.lg`: per public def its
  mode signature `{ params : [mode], ret : mode, escapes : bool }`.
- `lg check`/`emit`/`build` load `.lgi` when present (or when newer than
  the `.lg`); missing → current behavior (assume escapes).
- `.lgi` is text, checked into the repo optionally; `.gitignore` by
  default.

**Verify.** `util.lg` helper stays `Local` when compiled standalone vs.
through `.lgi` — assert via `lg modes` diff.

## 3. OxCaml backend

Lower the inferred modes to real OxCaml annotations; vanilla OCaml
output stays the always-working path.

- `Local` → `let x = stack_ (expr) in` / `@local` on parameters and
  returns where the signature permits.
- `Owned` → `unique` mode on the binding; `Deref`/`Move` reuse sites get
  uniqueness-preserving calls.
- Build path: `lg build --backend=oxcaml` uses an `ocamlfind` toolchain
  with `flambda2`/`oxcaml` packages; `--backend=ocaml` (default) is
  unchanged. The OxCaml typechecker re-verifies our inference — a wrong
  `Local` is a build failure there, which is the point.
- Gate behind `LG_OXCAML=1` in the environment blueprint since it needs
  a second opam switch.

**Verify.** `test/oxcaml.lg` compiled on both backends; compare outputs
byte-for-byte; `lg modes` agrees with OxCaml's mode check.

## 4. FBIP / Perceus-owned reuse

Turn `Owned` collection updates into in-place mutation when provably
unique.

- Reuse analysis in `modes.ml`: a binding whose count is 1 at an
  update site gets a *reuse token*.
- Emitter: `conj`-chains on `Owned` vecs emit `rrbvec`'s transient
  push + `persistent!` instead of persistent append; same for
  `into`-folds and `(transient …)`-style builders (add `transient` /
  `persistent!` builtins for the manual form too).
- Soundness: reuse token only fires when the mode proof is `Owned` —
  never guess.

**Verify.** `test/fbip.lg`: an Owned conj-chain produces one transient
alloc (assert via `Gc.quick_stat` minor_words delta under a bound);
aliased binding stays persistent.

## 5. Private API surface

- `^{:private true}` on a defn keeps it out of the module's exports;
  cross-module reference is a compile error.
- `.lgi` doubles as the export manifest (§2) — a def missing from it is
  private.
- `ns` form grows `(:export [names…])` as the explicit alternative to
  private-by-annotation.

**Verify.** `should_fail/private.lg` references a private def and must
fail `lg check`.

## 6. `--strict` dyn mode

- `lg check --strict`: mixed-type literals and any implicit `any`
  introduction require an explicit `^any`. Effect: the only `any` in a
  program is one the author wrote down.
- Emits a per-site error `strict: heterogeneous literal requires ^any`.

**Verify.** `should_fail/strict.lg` fails under `--strict` and passes
without it.

## 7. Smaller items (pull in as needed)

- `defrecord` → `TCon` + positional constructor + `match` on it;
  records are the typed answer to hetero maps.
- `loop`/`recur` special form with arity-checked recur targets.
- `cond`, `case`, `->>` macros in `core.lg` (already have `->`).
- Varargs `& rest` on defn arity (pair with multi-arity).
- Error spans: underline the offending form in check output.
