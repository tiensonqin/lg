core

The lg core library — special forms and builtins available unqualified in every module.

Special forms

def · defn · defmacro · defvariant · declare · extern-type · ffi · :require · fn · let · if · cond · case · match · do · and · or · when · when-let · if-let · try · quote · quasiquote · -> · ->> · & · #_

defspecial form
(def name "doc"? expr)

Bind NAME to the value of EXPR at module top level. The type is inferred and generalized; an optional docstring precedes EXPR.

defnspecial form
(defn name "doc"? [params] body…)

Define a function. Sugar for (def name (fn [params] body…)). Multi-arity (defn f ([x] …) ([x y] …)) dispatches on argument count.

defmacrospecial form
(defmacro name "doc"? [params] body…)

Define a compile-time macro. Receives unevaluated argument forms and returns a form; multi-arity clauses are supported like defn.

defvariantspecial form
(defvariant (name 'a…) "doc"? (ctor field…)…)

Define a closed variant type with named constructors. Constructors become functions; `match` on the type warns on missing ctors.

declarespecial form
(declare ^(fn [t…] r) name)

Forward-declare NAME's type for mutual recursion or to pin a concrete signature that inference would widen (e.g. a collection parameter).

extern-typespecial form
(extern-type name)

Declare an opaque handle type for values that cross the ocaml.* interop boundary (e.g. (extern-type conn) for a socket).

ffispecial form
(ffi name [arg…] ret {:ocaml "M.f" | :native "c" | :js "f"})

Bind an external function directly — no wrapper. The module requires the matching backend (ocaml.pkg/native lib/js).

:requirespecial form
(:require [ns :as alias] [ocaml.Mod] [mod :refer (n…)])

Module-level import: lg modules qualify as ns/name, OCaml library modules as ocaml.Mod members (e.g. olist/find).

fnspecial form
(fn name? [params] body…) | (fn ([x] …) ([x y] …))

Anonymous function; an optional name enables self-recursion (named fn compiles to `let rec`, native TCO applies).

letspecial form
(let [name expr …] body…)

Sequential binding pairs; later bindings see earlier names. `name` may destructure a tuple [a b], vector [a & r], or map {k v}.

ifspecial form
(if cond then else?)

Two-branch conditional; a missing else yields unit. Branch types join per §4 (unit widens to option).

condspecial form
(cond test expr … :else expr)

Ordered multi-branch conditional; evaluates tests in order, returns the first matching expr, :else as the default.

casespecial form
(case e (pattern… result)…)

Match an expression against literal values (atoms); arms with several patterns share one result.

matchspecial form
(match scrutinee (pattern expr)…)

Structural pattern match: literals, binders, [vec] {map} destructuring, option (Some x)/None, variant ctors, & rest in vector patterns. Non-exhaustive matches warn W401/W402.

dospecial form
(do expr…)

Evaluate expressions in order; the value is the last one.

andspecial form
(and expr…)

Left-to-right short-circuit; returns the first falsy value or the last.

orspecial form
(or expr…)

Left-to-right short-circuit; returns the first truthy value or the last.

whenspecial form
(when cond body…)

Evaluate body when cond is truthy; otherwise unit.

when-letspecial form
(when-let [name expr] body…)

Bind NAME to the Some payload of EXPR and run body when it matches (Some name); unit otherwise.

if-letspecial form
(if-let [name expr] then else?)

Like when-let with an else branch taken when EXPR is not (Some name).

tryspecial form
(try body… (catch e handler…) (finally f…))

Real OCaml exceptions: BODY runs inside try..with; E binds the opaque exn handle for HANDLER; FINALLY always runs (Fun.protect), its value discarded. The try's value joins body and handler.

quotespecial form
(quote form) | 'form

Return FORM unevaluated as data (symbols, lists, literals).

quasiquotespecial form
`form  with  ~unquote  ~@unquote-splicing

Templated form construction: ` quotes, ~ evaluates a subform, ~@ splices a seqable's elements in place.

->special form
(-> x (f a) (g b)) = (g (f x a) b)

Thread-first: insert X as the first argument of each successive form; desugars at read time.

->>special form
(->> x (f a) (g b)) = (g b (f x a))

Thread-last: insert X as the last argument of each successive form; desugars at read time.

&special form
[a b & rest]

Rest parameter: in fn/defn/defmacro params and vector match patterns, binds the remaining elements as a list.

#_special form
#_form

Reader discard: the next form is read and dropped — no value, no evaluation.
