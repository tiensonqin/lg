module lib/test.lg — lg stdlib
deftestmacro
(fn [symbol] unit)

(t/deftest name body...) registers a zero-arg test under a quoted name, in definition order.

ismacro
(fn [bool] unit)

(t/is form) checks a boolean form; reports FAIL <name>: <form> on failure.

testingmacro
(fn [string] unit)

(t/testing msg body...) adds a context label to failures inside the body.

aremacro
(fn [vec] unit)

(t/are [x y] expr arg...) expands rows into t/is checks: (are [x y] (= x y) 1 1 2 2).

run-testsdef
(fn [] int)

Run every registered deftest in definition order. Returns the failure count - feed to exit.
